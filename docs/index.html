A unified package manager CLI for Windows. Define your entire software stack in a single YAML file and manage it with one command.

⬇ Download latest ★ View on GitHub

Features

📦

Multi-source support

Install packages from winget, chocolatey, scoop, GitHub releases, and direct URLs — all in one config.

📄

Declarative configuration

Define your entire software suite once in packages.yaml, version control it, and replicate it across machines.

🔗

Config imports

Split your configuration across multiple files and compose them with import: — supports recursive imports and circular-import detection.

🪝

Lifecycle hooks

Run shell commands before (pre_install) and after (post_install) each package action.

🔄

Self-updating

AppTide can detect and install its own updates automatically with apptide selfupdate.

✅

Validation & verification

Built-in health checks to ensure configurations are valid and systems are in the desired state.

🗂

Organized by category

Group applications into logical categories (Development, Browsers, DevOps, CLITools, etc.) for clarity and maintainability.

📊

Structured output

All commands support --output json for scripting and CI/CD integration.

🔍

Category filtering

Use --category to scope install and verify to a single group of packages.

Installation

# 1. Download the binary for your platform from the releases page
#    https://github.com/lucasassuncao/apptide/releases

# 2. Extract apptide.exe to a directory in your Windows PATH
git clone https://github.com/lucasassuncao/apptide.git
cd apptide
go build -ldflags "-X github.com/lucasassuncao/apptide/cmd.Version=v1.0.0" -o apptide.exe .

Quick start

Initialize a config, then manage your packages.

apptide init              # create packages.yaml from minimal template
apptide init -i           # interactive wizard
apptide validate          # validate your config
apptide list              # list all configured packages
apptide install           # install all packages
apptide verify            # check which packages are installed
apptide doctor            # diagnose system health

Configuration example

import:
  - ./configs/gaming.yaml
  - ./configs/work.yaml

Development:
  - name: "VS Code"
    source: winget
    id: "Microsoft.VisualStudioCode"
    action: install

  - name: "Lazygit"
    source: github
    repo: "jesseduffield/lazygit"
    version: "latest"
    action: install
    post_install: "echo Lazygit ready"

CLITools:
  - name: "jq"
    source: winget
    id: "jqlang.jq"
    action: install

Commands

Command Description
apptide initCreate a packages.yaml from a minimal template or interactive wizard
apptide listDisplay all configured packages and their metadata
apptide installInstall or update all packages marked with action: install
apptide install --category DevelopmentInstall packages in a specific category only
apptide verifyCheck which packages are installed and detect version mismatches
apptide validateVerify YAML configuration syntax and completeness
apptide doctorDiagnose system health and check package manager availability
apptide exportExport current system state as a packages.yaml template
apptide selfupdateDownload and apply the latest AppTide release
